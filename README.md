# Snake

The classic snake game, playable in the browser. Plain HTML, CSS and JavaScript, with no build step and no dependencies.

**Play:** https://haaktuah.github.io/snake-game/

## Controls

| Action  | Keys                         |
|---------|------------------------------|
| Move    | Arrow keys or WASD (swipe on touch screens) |
| Pause   | Space or P                   |
| Restart | Enter or R                   |

Eat the red food to grow. The snake speeds up as it grows. Don't hit the walls or yourself. Your best score is saved in the browser.

## Run locally

Open `index.html` in any browser.
