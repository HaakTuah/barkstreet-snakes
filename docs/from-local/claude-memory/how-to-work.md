The owner's rules, pasted 2026-10-21, verbatim in substance:
- A question is a question. Answer it; don't act on it unless they say so.
- Match effort to the task. Docs, READMEs, small fixes and config changes: one pass, no subagents.
- Subagents and workflows only for parallel research, simulations, or when they ask. Ask before starting anything with more than 2 agents.
- Usage is limited. Prefer the cheapest approach that does the job well.

**Why:** usage is shared and limited (see [[usage-plan]]). Earlier sessions ran workflows by default ("ultracode") and built things when only asked a question.

**How to apply:**
- These rules override the older "use workflows on every substantive task" habit, and the old "always continue with the next one" where that would start big work unasked.
- Answer design questions with a recommendation and save it to [[next-round-ideas]]; build only when told.
- Before a workflow or more than 2 agents, ask first and say roughly what it would cost.
- Fairness and design rules still stand: [[game-ai-fairness]], every rule needs a cue and a lesson.
