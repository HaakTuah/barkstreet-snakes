# Claude and Codex: what goes to whom

This game's own table of what goes to whom, and its trial, for the orchestrator once Codex can build; Codex's status,
the hand-over and the rest: `core/modules/codex-building.md`. A draft PR labelled `codex` is a claimed lane like any
other.

| Claude decides and builds | Codex builds |
| --- | --- |
| The AI's planning (search included) and every rival's trademark | Layout and interface fixes |
| Engine rules and new moves (the A/B judgment: "Using a feature must pay" in `core/modules/game-design.md`) | Render bugs that come with a repro |
| Online sync (whole) and the protocol | Splitting files and tests, proven by fingerprints and the suites |
| Chatter lines and lesson texts (the voice) | Keeping the browser suites working |
| What a change should feel like, from the owner's feedback | What Claude has specified as tests: a move's cue and lesson wiring, a rule's implementation, A/B runs and their tables |
| | Docs that record what is decided, and the PR-picture tooling |

**Trial:** in the first week Codex can build, one art or animation task to Codex, compared against Claude's; after
that, art goes where it scored better.
