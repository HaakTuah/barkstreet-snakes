> I want to run them both together, so that they collaborate and spread the usage, and can last about the full week.

> Can't the orchestrator just create Codex builder instances, like it does internally now, and split the load? And maybe

> The Claude Code orchestrator must be aware that there will be times when Codex isn't available. It should make a habit
